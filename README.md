# Task-09.25 — 2D-шутер на выживание

Тестовое задание на Unity и C#: герой отбивается от врагов, которые появляются за пределами экрана и преследуют его. В прототипе доступны пистолет и дробовик, обычные противники и противники с рывком. На экране отображаются здоровье и время игры.

**Unity:** 2022.3.9f1 · **Сцена:** [SampleScene](Assets/Scenes/SampleScene.unity)

## Условие задания

| Область | Требование |
| --- | --- |
| Движение | Управление героем стрелками или WASD. |
| Стрельба | Пули летят в сторону указателя мыши при нажатии ЛКМ. |
| Оружие | Не менее двух видов оружия со свободным переключением, например одиночный выстрел и залп. |
| Враги | Случайное появление за экраном, движение к герою и урон при касании. Несколько видов врагов приветствуются. |
| Завершение игры | Игра заканчивается, когда у героя кончаются жизни. |
| Код | По возможности избегать готовых решений, учитывать расширяемость и производительность. Zenject запрещён; самописное внедрение зависимостей приветствуется. |

## Реализация

Герой начинает с 50 единицами здоровья. Камера следует за ним, а враги появляются каждые 0,5 секунды с одной из четырёх сторон за видимой областью. Обычный противник движется к герою с постоянной скоростью; второй тип периодически ускоряется рывком. При контакте противник наносит урон и исчезает.

Пистолет выпускает одну пулю, дробовик — пять пуль веером с разбросом 30°. У каждого оружия свои задержка между выстрелами, скорость и время жизни пуль. Удержание ЛКМ позволяет стрелять непрерывно с учётом этой задержки.

**Управление:**

- **WASD / стрелки** — движение.
- **Мышь + ЛКМ** — прицеливание и стрельба.
- **ПКМ** — переключение между пистолетом и дробовиком.

При нулевом здоровье герой перестаёт двигаться и стрелять, появляется панель **Game Over** с кнопкой **Restart**. Перезапуск заново загружает текущую сцену и восстанавливает обычную скорость времени.

## Технические решения

| Решение | Применение |
| --- | --- |
| Компоненты и абстракции | Ввод, здоровье, движение, атака и оружие выделены в отдельные компоненты. Варианты оружия и врагов реализованы через общие базовые классы. |
| Связывание компонентов | Ссылки задаются в сцене и префабах, часть компонентов находится через `TryGetComponent`. DI-контейнер и Zenject не используются. |
| Пулы объектов | Самописный `ObjectPool<T>` повторно использует неактивные пули и врагов, создавая дополнительные экземпляры при нехватке. Перед повторным появлением врагу восстанавливается здоровье и задаётся цель. |
| Настройки и события | Параметры оружия, врагов и спавна сериализуются в префабах и сцене. Ввод сообщает о стрельбе и смене оружия через события, здоровье — об уроне и смерти; UI обновляется по событиям здоровья. |

## Текущее состояние

После смерти героя время замедляется до `Time.timeScale = 0.1`, но спавн врагов и таймер продолжают работать. Панель завершения игры не ставит мир на полную паузу и не фиксирует итоговое время.
